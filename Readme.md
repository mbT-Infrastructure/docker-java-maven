# Java Maven image

This container image contains a Java and Maven installation.

## Installation

1. Pull from [Docker Hub], download the package from [Releases] or build using `builder/build.sh`

## Development

To build and run the docker container for development execute:

```bash
docker compose --file docker-compose-dev.yaml up --build
```

[Docker Hub]: https://hub.docker.com/r/madebytimo/java-maven
[Releases]: https://github.com/mbt-infrastructure/docker-java-maven/releases
